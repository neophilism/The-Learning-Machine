# Module 1: selective masking journey

Module 1 uses the versioned `intro-visual-reasoning` lesson graph and the real browser-local `synthetic-masking-v1` pixel experiment.

The normal encounter-through-transfer route requires a learner to compare selective masking, which scans generated pixels for the target, with either blanket masking or known coordinates, which do not perform target recognition. Both runs use the same original 64 by 36 generated frame. The observation stage retains computed evidence from each run; authored explanations and counterexamples remain clearly labeled.

The direct-explanation route stays available without a punitive score. Learners may revise or defend their hypothesis, and completion depends on recording reasoning plus a novel transfer case, not agreement with a policy position. Browser tests exercise the comparison gate, keyboard activation, mobile layout, reasoned disagreement and a plausible alternative outcome. No account, webcam or network write is required.
