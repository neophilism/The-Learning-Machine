# Safety, Privacy, and Editorial Integrity

- Local-only user drawings/video/audio by default; explicit gestures for media permissions; no default media upload.
- Core modules work without account, remote tutor, paid API, external GPU or billing.
- Use synthetic or permissioned examples and preserve source/asset rights metadata.
- A real learning classifier may memorize; no unqualified claims about model deletion or physical memory erasure.
- Model real computation honestly; illustrative numbers/flows are always distinguished from observations.
- Distinguish current U.S. law from sponsor's interpretations, draft bill and open legal questions.
- Do not score political agreement or steer learners by withholding experiments from dissenters.
- Publisher-only auth/MFA; original bytes validation, CSP, worker resource limits, source hash verification, robust sandbox and CI security checks.
- Equivalent no-audio, keyboard, low-power and screen-reader lessons; avoid collection of child personal data without separately designed consent compliance.
- Any optional conversational provider receives minimum authorized context, validated outputs, rate limits and deletion/retention policy.
