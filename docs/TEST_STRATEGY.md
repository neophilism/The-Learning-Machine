# Verification and Acceptance Plan

**Foundation:** `npm run check` validates all 96 roadmap units, DAG and permitted status/merge evidence; `npm test` executes a real Node built-in test suite of miniature Socratic transitions and alternative hypotheses. No cloud keys.

**Incremental:** Every PR specifies behavior and executable tests. TLM-002 introduces pinned Node24+pnpm+TypeScript toolchain and CI lockfile, later Playwright, property-based checks, source-citation snapshots, media privacy network isolation, worker resource stress and assistive-technology routes.

**Quality contract:** Tests must prove actual training or pixel/audio calculations rather than check mocked promises. A deterministic numerical oracle verifies reproducible runs. Browser GPU differences get disclosed tolerances; no false claim of determinism.

**Release:** Test all eight lessons, including nonagreement, direct explanation, denied camera/microphone, disabled AI, low power and offline runs. G11 needs independent deployed origin, exact release hashes, content evidence, rollback and incident drills. A green plan validator alone is never feature implementation evidence.
