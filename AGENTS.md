# Coding Agent and Contributor Instructions

The Learning Machine is standalone and technically independent of other products. Do not adopt another product's schemas, runtime, APIs, release pipeline, services or data dependencies.

Read `docs/DEVELOPMENT_PLAN.md`, `docs/ARCHITECTURE.md`, `registry/prs.json` before working. Each TLM ID is an acceptance unit, not a live GitHub PR number. Only a fully implemented, tested, head-verified, merged change counts complete. Record true dependencies, tests, source evidence and merge SHAs; never invent partial implementations or PR statuses. Work another dependency-ready unit if blocked. No political-conformity scoring, invented measurements or legal authorities. Keep visitor media local by default and all core lessons accessible without optional AI. Update tests, docs and immutable release metadata with behavior changes.
